# AI Tools Lab

## Project Description

AI Tools Lab is a Python project developed to practice GitHub workflows, sorting algorithms, and reusable utility functions with the assistance of AI tools.

The project demonstrates basic version control practices such as commits, branches, pull requests, and collaborative code development.

## Features

* Bubble sort algorithm
* Palindrome checking
* Word counting
* Celsius to Fahrenheit conversion
* Git and GitHub version control workflow
* AI-assisted code generation and documentation

## Installation

1. Clone the repository:

```bash
git clone https://github.com/twinklesharma3174-cloud/ai-tools-lab.git
```

2. Navigate to the project directory:

```bash
cd ai-tools-lab
```

3. Run the Python files using Python 3 or later.

## Usage

### Bubble Sort

```python
from sorting import bubble_sort

numbers = [64, 34, 25, 12, 22, 11, 90]
print(bubble_sort(numbers))
```

### Utility Functions

```python
from utils import is_palindrome, count_words, celsius_to_fahrenheit

print(is_palindrome("madam"))
print(count_words("Hello Python World"))
print(celsius_to_fahrenheit(25))
```
